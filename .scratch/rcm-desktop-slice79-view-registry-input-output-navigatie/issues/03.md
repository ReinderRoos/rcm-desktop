# Issue 03 — Sticky view per zijde + Input-placeholder + persistentie

**Triage:** done  
**Type:** AFK

## Parent

PRD: `.scratch/rcm-desktop-slice79-view-registry-input-output-navigatie/PRD.md` (slice 79).

## What to build

De werkruimte onthoudt per zijde de laatst gekozen view en bewaart die keuze
tussen sessies.

End-to-end:

- Werkruimte-state: actieve zijde + sticky view-id per zijde; zijde-switch
  herstelt de laatst actieve view van die zijde (Output → Input → Output
  komt terug waar je was).
- Orchestrator plant zichtbaarheid op basis van (zijde, view-id).
- De Input-zijde toont een nette placeholder zolang er geen Input-panelen
  zijn (komen in slice 83).
- Persistentie van actieve zijde + sticky views via `QSettings`, naar het
  patroon van bestaande werkruimte-instellingen.

## Acceptance criteria

- [ ] Sticky-gedrag: Output→Input→Output herstelt de eerdere Output-view
      (orchestrator-test, Qt-vrij).
- [ ] Input-zijde toont een placeholder; geen crash, geen leeg gat.
- [ ] Zijde- en view-keuze overleven een venster-herstart (`QSettings`).
- [ ] Onbekende/verdwenen view-id in settings valt terug op de default-view
      van de zijde.
