# Issue 02 — Beeld-submenu's + sneltoetsen uit de registry

**Triage:** done  
**Type:** AFK

## Parent

PRD: `.scratch/rcm-desktop-slice79-view-registry-input-output-navigatie/PRD.md` (slice 79).

## What to build

Menu **Beeld** krijgt submenu's **Input** en **Output**, gegenereerd uit de
view-registry — geen handmatige duplicatie in de menubalk-spec.

End-to-end:

- Beeld-submenu's met dezelfde views als de dropdown; het actieve item is
  aangevinkt en spiegelt de view-keuze.
- Sneltoetsen: `Ctrl+1` (Input), `Ctrl+2` (Output), `Ctrl+Alt+1..n`
  (view binnen de actieve zijde, volgorde = registry-volgorde).
- Registratie via de bestaande menubalk-spec zodat de
  uniciteitsvalidatie (slice 76) de nieuwe sneltoetsen meeneemt.
- Menu-keuze, dropdown-keuze en sneltoets leiden tot exact hetzelfde
  gedrag (één bron van waarheid: de registry).

## Acceptance criteria

- [ ] Beeld bevat submenu's Input en Output met alle registry-views.
- [ ] `Ctrl+1`/`Ctrl+2` wisselen van zijde; `Ctrl+Alt+1..n` wisselen van view
      (pytest-qt).
- [ ] Spec-validator dekt de nieuwe sneltoetsen; golden spec-test bijgewerkt.
- [ ] Actieve view is aangevinkt in het menu en blijft in sync met de
      dropdown.
