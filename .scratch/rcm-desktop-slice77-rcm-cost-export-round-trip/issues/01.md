## What to build

Bewaar bij import een kopie van de originele AW-workbook als **AW-bron-sidecar**.

- Voeg aan `project_path_resolution_service` een `source_workbook_path()` toe →
  `<project_stem>.rcm.source.xlsx` (zelfde conventie als `cache_path()`).
- Schrijf in `persist_import_wizard_result` (`isograph_open_flow_service`) een
  **kopie** van de gekozen Excel naast het opgeslagen `.rcm.json`.
- Leg het pad vast in `import_settings["source_workbook_path"]` (relatief t.o.v. de
  projectmap waar mogelijk). Erken de key expliciet in
  `import_settings_contract` (pass-through blijft, maar gedocumenteerd).

## Acceptance criteria

- [ ] Na import bestaat `<project>.rcm.source.xlsx` naast het `.rcm.json`.
- [ ] `import_settings["source_workbook_path"]` wijst naar de sidecar.
- [ ] JSON round-trip (`save`/`load`) behoudt de key (pass-through-contract).
- [ ] Bestaande importtests blijven groen; geen wijziging aan de mapper-output.
- [ ] `source_workbook_path()` getest op `ResolvedProjectPath`.
