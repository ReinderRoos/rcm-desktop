## What to build

Een **Qt-vrije export-service** (`rcm_desktop/adapter/isograph_export_service.py`)
die de AW-bron-sidecar her-emitteert met de bewerkte must-v1 velden gepatcht.

- Laad de sidecar met openpyxl (behoud alle 25 sheets en niet-gemodelleerde cellen).
- Patch per must-v1 sheet de bewerkte velden uit `RCMProject` op de **bestaande
  rij**, gematcht op de behouden AW-ID / gereverseerde synthetische sleutel
  (`pm_id = Cause|TaskId|SubIndex`, `link_id` → assignment-rij). Hergebruik de
  formules uit `isograph_import_service` / `isograph_pm_import_rules` (geen
  duplicatie).
- Volg het reverse-mapping-contract uit de PRD-tabel (RcmCauses, RcmEffects,
  RcmCauseEffectAssignments, RcmCorrectiveTasks, RcmScheduledTasks, RcmLocations,
  RcmFunctions, TaskGroups, Project).
- Schrijf naar een **apart** output-pad (overschrijft de bron niet).

## Acceptance criteria

- [ ] **No-op:** import → export zonder bewerking → alle 25 sheets inhoudelijk gelijk
      aan de bron (mod. celnormalisatie).
- [ ] **Patch:** een bewerkt `FmMttf` (en andere must-v1 velden) verschijnt op de
      juiste `RcmCauses`-rij; ongemodelleerde sheets ongewijzigd.
- [ ] **Round-trip:** export → `build_from_sheets` reproduceert het bewerkte
      `RCMProject` (sleutelvelden gelijk).
- [ ] Match gebeurt op behouden AW-ID / gereverseerde sleutel (geen positionele
      aanname).
- [ ] Service is Qt-vrij en unit-getest met de `tests/fixtures/`-workbooks.
