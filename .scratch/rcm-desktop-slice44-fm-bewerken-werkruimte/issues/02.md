## What to build

Eerste **end-to-end tracer** voor de analist: in modus **FM-detail** opent **dubbelklik** op een FM-rij een **modale** `FmEditorDialog` met minimaal tabbladen **Basis** en **Correctief** (overige tabs als lege placeholder of disabled met korte melding “volgt in issue 03/04”).

**Basis-tab**

- Faaltype `random` / `aging`; MTTF; sigma (zichtbaar/relevant bij aging).
- NMF ja/nee ↔ `is_evident` (Ja = niet merkbaar).
- Faalscenario-omschrijving, functie-FK, optioneel `repair_quality`.
- Startleeftijd via PBS `bouwjaar` met waarschuwing bij gedeeld PBS (meerdere FM’s opzelfde `pbs_id`).

**Correctief-tab**

- CM-kosten via `CmCostSplitMapper` (materiaal + arbeid).
- Hersteltijd (`downtime_per_failure` in uren voor de gebruiker).
- Scenario-teksten (`notes`, `aanname_cm_kosten`, `aanname_downtime`).

**Dialoog-gedrag**

- Titel: `fm_id`, omschrijving, PBS/bouwdeel.
- **Annuleren**: sessie weg, parent-project ongewijzigd.
- **OK**: geblokkeerd bij validatiefouten (NL-meldingen); anders `FmEditCommitService` → incrementele run → werkruimte ververst (run + FM-tabel/inspector waar van toepassing).

**Resultatenwerkruimte**

- Alleen in modus FM-detail; dubbelklik op geselecteerde rij; geen editor in Top 10 / Tijdsplot.

Views praten alleen via adapter; geen `rcm_core`-imports in views (typing-only OK).

## Acceptance criteria

- [ ] Dubbelklik in FM-detail opent modale editor voor die `fm_id`.
- [ ] Wijziging MTTF + OK → project in-memory bijgewerkt; incrementele run getriggerd (geen volledige recompute).
- [ ] Annuleren laat MTTF (en overige velden) ongewijzigd t.o.v. open-moment.
- [ ] OK geblokkeerd bij pipeline-validatiefout (bijv. MTTF ≤ 0).
- [ ] NMF “ja” zet `is_evident=False` na commit.
- [ ] CM-split: ingevoerde materiaal+arbeid = opgeslagen `cost_cm_eur`.
- [ ] Waarschuwing zichtbaar bij PBS gedeeld door >1 faalwijze.
- [ ] pytest-qt smoke: open dialoog → wijzig veld → OK → FM-tabel of inspector toont verwachte wijziging / her-run status.
- [ ] Geen dubbelklik-handler buiten FM-detail.
