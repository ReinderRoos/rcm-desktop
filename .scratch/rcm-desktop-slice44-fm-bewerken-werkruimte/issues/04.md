## What to build

Voltooi `FmEditorDialog` met tabblad **Preventief** voor onderhoudsprogramma van de actieve faalwijze.

**PM-taken**

- CRUD op `pm_tasks` gefilterd op `fm_id`: type (IN, TST, REV, SVO), interval, kosten, onbeschikbaarheid, omschrijving, koppeling `task_group_id`.

**Taakgroepen**

- Bij selectie van een taak met `task_group_id`: inline bewerken van `task_groups` (interval, kosten, duur, onbeschikbaarheid).
- Waarschuwing als de groep ook door andere faalwijzen wordt gebruikt.

**PM-effectlinks**

- Beheer per PM-taak (zelfde semantiek als issue 03, maar vanuit PM-tab context).

Commit en incrementele run via `FmEditCommitService`; waarschuwing bij gedeelde taakgroep-wijziging.

## Acceptance criteria

- [ ] Tab Preventief functioneel; geen placeholder.
- [ ] Nieuwe PM-taak voor actieve FM kan worden toegevoegd en na OK in project aanwezig.
- [ ] PM-taak kan worden verwijderd; validatie voorkomt inconsistente FK’s.
- [ ] Taak gekoppeld aan taakgroep: wijziging interval/kosten op groep slaat op in `task_groups` en waarschuwt bij gedeeld gebruik.
- [ ] PM-effectlink op nieuwe taak kan worden toegevoegd.
- [ ] OK na PM-wijziging triggert incrementele run; FM van deze taak in `affected_fm_ids`.
- [ ] pytest-qt of unit: PM CRUD + commit op fixture.
- [ ] Alle vier tabs (Basis, Effecten, Correctief, Preventief) beschikbaar in één dialoog.
