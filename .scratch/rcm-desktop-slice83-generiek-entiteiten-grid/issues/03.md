# Issue 03 — Correctief onderhoud als projectie van Faalwijzen

**Triage:** ready-for-agent  
**Type:** AFK

## Parent

PRD: `.scratch/rcm-desktop-slice83-generiek-entiteiten-grid/PRD.md` (slice 83).

## What to build

De vijfde Input-view: **Correctief onderhoud** — geen eigen entiteit maar
een **projectie** van de faalwijzen-entiteit met de CM-kolomset.

End-to-end:

- Projectie-mechanisme op het generieke grid: kolomsubset (CM-velden zoals
  CM-kosten, downtime per faling, repair quality, hersteld-aannames) op
  dezelfde faalwijzen-entiteit.
- Een bewerking in de projectie is een bewerking van de faalwijze — één
  bron van waarheid; de wijziging is direct zichtbaar in de Faalwijzen-view
  (gedeeld dirty-mechanisme).
- Projectie-definitie Qt-vrij en golden-getest (kolomsubset + mapping naar
  faalwijze-velden).

## Acceptance criteria

- [ ] Correctief-onderhoud-view opent onder Input met de CM-kolomset.
- [ ] Bewerking in de projectie wijzigt de onderliggende faalwijze
      (pytest-qt + pipeline-test).
- [ ] Wijziging in de ene view is zichtbaar in de andere zonder herladen.
- [ ] Projectie-definitie golden: kolomsubset klopt, mapping wijst naar
      faalwijze-velden.
