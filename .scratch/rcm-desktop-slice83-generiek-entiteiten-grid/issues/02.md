## Parent

PRD: `.scratch/rcm-desktop-slice83-generiek-entiteiten-grid/PRD.md` (slice 83).

## What to build

Drie extra Input-views als pure configuratie op het generieke grid — het
bewijs dat uitbreiden goedkoop is.

End-to-end:

- **REV-taken**: de `pm_tasks`-entiteit met REV-relevante kolompreset
  (afgeleide PM-kolommen volgen in slice 84). Label "REV-taken" via
  `messages`; het schema blijft `pm_tasks`.
- **Effecten**: `effect_klassen`-entiteit met preset.
- **Taakgroepen**: `task_groups`-entiteit met preset.
- Elke view: bewerkbaar via de pipeline, filterrij actief, registry-entry
  enabled (placeholder weg).

## Acceptance criteria

- [ ] Drie views openen onder Input met hun preset-kolommen.
- [ ] Per view is alleen configuratie toegevoegd (geen nieuwe grid-logica).
- [ ] Celbewerking + FK-validatie werkt in elk van de drie views
      (geparametriseerde test).
- [ ] Presets golden-getest tegen het schema.
