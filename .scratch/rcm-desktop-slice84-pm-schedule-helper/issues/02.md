# Issue 02 — Afgeleide PM-kolommen in het REV-taken-grid

**Triage:** ready-for-agent  
**Type:** AFK

## Parent

PRD: `.scratch/rcm-desktop-slice84-pm-schedule-helper/PRD.md` (slice 84).

## What to build

De REV-taken-tabel toont per taak de afgeleide planningskolommen, altijd
actueel zonder run.

End-to-end:

- Adapter-viewconfig voor REV-taken: kolommen **Eerste jaar uitvoering**,
  **Interval (jaar)**, **Kosten taak (EUR)** en **Aantal uitvoeringen in
  LCC-periode**; de afgeleiden komen uit de pm_schedule-helper.
- Afgeleide kolommen zijn herkenbaar **read-only**; invoerkolommen
  (interval, kosten, startjaar) blijven bewerkbaar.
- Wijziging van interval of startjaar ververst de afgeleiden direct (pure
  functie, geen run nodig).
- Horizonbron = dezelfde projecthorizon als de motor (LCC-periode); geen
  aparte UI-aanname.
- Geen schemawijziging in `ENTITY_SCHEMAS` (afgeleiden zijn presentatie).

## Acceptance criteria

- [ ] REV-taken-grid toont de vier kolommen met helperwaarden.
- [ ] Interval-wijziging ververst eerste jaar + telling direct, zonder run
      (pytest-qt).
- [ ] Afgeleide kolommen zijn niet bewerkbaar; bewerken-poging wijzigt niets.
- [ ] Geen wijziging aan `ENTITY_SCHEMAS`; parity-tests groen.
