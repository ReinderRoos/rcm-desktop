## What to build

Lever het **eerste end-to-end pad** voor Modelinstellingen: van domain model tot zichtbaar dialoog in de resultatenwerkruimte.

**Kern (domain model + persistentie):**

- Voeg top-level **`projectnaam`** en **`modelleur`** toe aan `RCMProject` (optionele strings, default leeg).
- Zorg dat metadata **niet** globale digest / FM-invoerhash invalideert (exclude in digest-builder of equivalent — kies één aanpak en documenteer in code).
- Bestaande **`lifecycle_years`** en **`modeljaar`** uit `RCMConfig` zijn bewerkbaar via het dialoog.

**Adapter (Qt-vrij, test-first):**

- Introduceer **`model_settings_service`** met minimaal:
  - `build_draft(project) -> ModelSettingsDraft`
  - `validate_draft(draft) -> errors`
  - `commit_draft(project, draft, *, project_path, save_to_disk) -> CommitResult` inclusief `requires_rerun: bool`
- **`requires_rerun`** is `True` bij wijziging `lifecycle_years` of `modeljaar`; `False` bij alleen `projectnaam`/`modelleur`.

**UI:**

- Knop **Modelinstellingen** in de **resultatenwerkruimte**-toolbar (alleen wanneer project geladen).
- Modaal **`ModelSettingsDialog`** met secties **Project** (projectnaam, modelleur) en **Horizon & tijd** (lifecycle, modeljaar, read-only regel “bucket-interval: 1 kalenderjaar”).
- Titeltemplate: `Modelinstellingen — {projectnaam of bestandsnaam}`.
- **Dirty-guard** op faalwijzen batch-grid vóór openen (zelfde patroon als FM-editor).
- **OK:** valideer → werk sessie bij → **atomisch opslaan** bij bekend pad → toon/set **“herbereken vereist”** in werkruimte wanneer `requires_rerun` (geen auto-run in deze issue).
- **Annuleren:** verwerp draft.

Architectuurgrens: views praten alleen via adapter; geen directe `rcm_core`-mutatie vanuit views.

## Acceptance criteria

- [x] `projectnaam` en `modelleur` serialiseren/deserialiseren in `.rcm.json`; ontbrekende velden migreren als lege string.
- [x] Wijziging alleen projectnaam/modelleur triggert **geen** `requires_rerun`; wijziging lifecycle of modeljaar **wel**.
- [x] Metadata staat **niet** in globale digest (unit-test met identieke motorinvoer, andere metadata → zelfde digest).
- [x] Knop opent dialoog na dirty-grid guard; OK slaat atomisch op bij pad; validators blokkeren lifecycle ≤ 0.
- [x] Adapter unit-tests dekken draft, validate, commit en `requires_rerun`-logica; pytest-qt smoke opent dialoog en commit project+horizon.
