# Issue 03 — Veroudering defaults + bulk apply aging-faalwijzen

**Triage:** done  
**Type:** AFK

## Parent

PRD: `.scratch/rcm-desktop-slice52-modelinstellingen/PRD.md` (slice 52).

## What to build

Voeg **projectdefaults voor verouderingsdistributie** toe en een **expliciete bulk-apply** op aging-faalwijzen — end-to-end van config tot FM-velden.

**Kern:**

- `RCMConfig` uitbreiden:
  - `default_aging_distribution`: `"normal" | "truncated_normal_0" | "weibull_2p"` (default `"normal"`)
  - `default_beta_jaar: float = 0.0`
- Validators: bij default Weibull moet `default_beta_jaar > 0` (hard error, analoog slice 51 FM-validatie).
- **`apply_default_aging_to_fms(project, draft) -> ApplyAgingResult`** met `{count, fm_ids}` — alleen FM’s met `failure_type = aging`; zet `aging_distribution` en (bij Weibull) `beta_jaar`. Random-FM’s blijven ongemoeid.

**Adapter + UI:**

- Dialoog-sectie **Veroudering (defaults):** dropdown distributie (NL-labels consistent met FM-editor/grid), conditionele β-spinbox bij Weibull-default.
- Knop **“Toepassen op alle aging-faalwijzen”:** toon teller + bevestiging vóór mutatie; apply gebeurt **in het dialoog vóór OK**, niet automatisch bij OK.
- Zonder Apply: OK slaat alleen config-defaults op; bestaande per-FM keuzes blijven intact.
- Na Apply + OK: `requires_rerun` wanneer FM-velden gewijzigd zijn.

## Acceptance criteria

- [x] Config-defaults serialiseren met backward-compat (ontbrekend → `normal` / `0.0`).
- [x] Validator blokkeert Weibull-default zonder β > 0.
- [x] Apply werkt alleen op aging-FM’s; random-FM’s ongewijzigd; count klopt in bevestigingstekst.
- [x] FM’s krijgen `aging_distribution` + `beta_jaar` volgens draft-defaults na bevestigde Apply.
- [x] Dialoog + adapter unit-tests; geen auto-apply bij OK zonder knop.
