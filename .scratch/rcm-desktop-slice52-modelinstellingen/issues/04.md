## What to build

Rond Modelinstellingen af met **optionele rerun**, **Monte Carlo-preview** en **import-voorinvulling** — dunne vertical slice over commit-flow, UI en import.

**Commit + run:**

- Checkbox **“Direct herberekenen”** op OK (default **uit**); alleen **enabled** wanneer `requires_rerun`.
- Bij aangevinkt: na succesvolle commit start **incrementele run** (`full_recompute=False`) via bestaande run-runner/werkruimte-seam; ververs presentatie zoals FM-editor.
- Bij uit: alleen opslaan + “herbereken vereist”-banner (gedrag issue 01).

**UI — Monte Carlo-sectie:**

- Toon `monte_carlo_n` en `monte_carlo_seed` **read-only/disabled** met tooltip “Monte Carlo nog niet actief in desktop”.
- Waarden blijven serialiseren in JSON (geen MC-run in desktop).

**Import:**

- Bij Isograph-import: als `projectnaam` leeg is, voorinvullen uit `Description` of bestandsnaam (bestaande `import_settings["isograph_project"]` metadata als bron).
- `modelleur` niet auto-invullen in v1.

**Tests:**

- pytest-qt smoke: open dialoog → wijzig motorrelevant veld → OK met/zonder Direct herberekenen.
- Adapter-test: rerun-hook alleen aangeroepen wanneer checkbox aan + `requires_rerun`.
- Import-test: lege projectnaam wordt gevuld na import.

## Acceptance criteria

- [x] Checkbox default uit; disabled wanneer commit geen rerun vereist.
- [x] Met checkbox aan na motorrelevante wijziging start incrementele run en werkruimte toont ververste resultaten.
- [x] MC-sectie zichtbaar maar niet bewerkbaar; tooltip aanwezig.
