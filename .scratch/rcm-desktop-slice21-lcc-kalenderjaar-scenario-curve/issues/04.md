## What to build

Eén **end-to-end** pad: na een **geslaagde volledige analyse** (geen CM/PM-vergelijk) toont de desktop een **LCC-sectie in het resultaten-/overview-gebied** met **verwachte nominale EUR per kalenderjaar**, opgesplitst in **CM** en **PM**, **geaggregeerd op projectniveau**.

- **Kern (Qt-vrij):** bouw jaarlijks profiel: **CM** proportioneel aan **verwachte faalmomenten per kalenderbucket** (faalmodel-discretisatie), daarna **genormaliseerd** naar lifecycle-**CM** uit de bijbehorende **`RunResult`**; **PM** via **LTAP-/motorconsistente** jaarplanning op het **gematerialiseerde project** van die run, **gereconcilieerd** met lifecycle-**PM** (micro-tolerantie alleen waar nodig). Kalenderjaar = **modeljaar + horizonindex** (zelfde conventie als issue **01** / adapter-mapping).
- **Adapter Qt:** map `RunResult` + canoniek project → **`LCCChartInput`** met `mode="single_run"` en één `LCCScenarioCurve` / `single_curve` volgens PRD-contract.
- **Views:** embed een **herbruikbare** LCC-presentatiecomponent die **primair een tabel** toont (kolommen o.a. kalenderjaar, CM EUR, PM EUR, totaal); titels/tooltips: **verwacht**, **nominaal**, geen schijn-vergelijk.
- **Invalidatie:** sectie **wist** mee wanneer run-context/projectbasis voor die output verdwijnt (zoals andere run-output).
- **Tests:** kern (reconciliatie, randen horizon), adapter (`LCCChartInput`-sommen), minimaal **één** stabiele UI-/flow-check dat data zichtbaar is na mock/geslaagde run (pytest-qt of bestaand patroon).

Dit issue is de **eerste verticale tracer** voor slice 21 (tabel-eerst); oude monolithische tickets **`02.md`** / **`03.md`** zijn **superseded**.

## Acceptance criteria

- [x] Na **geslaagde volledige analyse** is **één** LCC-tabel zichtbaar bij **run-resultaten**, met **kalenderjaar**-kolom volgens `modeljaar + index`.
- [x] **Som kolom CM** en **som kolom PM** sluiten aan op **RunResult**-lifecycletotalen (tests met fixture).
- [x] **Geen** tweede scenario-kolom of vergelijkende legenda die een A/B impliceert.
- [x] Bij **geen geldige run** of **reset/ander project**: **lege state**, geen oude rijen.
