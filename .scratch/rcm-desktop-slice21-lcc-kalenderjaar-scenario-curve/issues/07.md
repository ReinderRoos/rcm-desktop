## What to build

**Verticale snede door kern-contract → adapter → geautomatiseerde verificatie** (nog **zonder** wijzigingen aan validate-window of QtCharts in deze issue — die volgen in **08**, zie merge-opmerking onderaan).

- **`LCCYearBucket`** (adapter-presentatiecontract): velden **`calendar_year`**, **`correctief_eur`**, **`preventief_eur`** — vervangt de semantiek van vroegere `cm_eur` / `pm_eur` per bucket. Optioneel **voorbereid** veld voor latere PM-subsplit (mag `None` / weggelaten blijven zolang tests slagen).

- **Builders** (`build_single_run_lcc_input`, `build_compare_lcc_input`): vullen de nieuwe velden met **dezelfde rekenlogica** als thans: jaarlijks **correctief** = bestaande faalmomenten-discretisatie + normalisatie naar **som lifecycle-correctief** uit `RunResult`/`FMResult`; jaarlijks **preventief** = LTAP-consistent profiel op het juiste **project-snapshot** + normalisatie naar **som lifecycle-preventief** uit die run. **Scenario-LCC** blijft gekoppeld aan **twee runs + twee gematerialiseerde projecten**; **huidig project** aan **één run + basisproject**.

- **Kern:** alleen wijzigen waar nodig voor **duidelijkheid** (comments, publieke namen van helpers) — **geen** wijziging aan faalmodel of scenario-clone-regels in deze issue.

- **Tests:** harde reconciliatie per modus — som buckets **`correctief_eur`** = som correctieve lifecycle-component uit `RunResult`; som **`preventief_eur`** = som preventieve lifecycle-component; zelfde floattolerantie als bestaande LCC-tests. Bestaande fixture(s) hergebruiken.

**Merge-opmerking:** Tot **08** is gemerged, kan de UI nog oude veldnamen tonen — in de praktijk **07+08 in één PR** of **08 direct erna** zonder tussen-release om half-broken desktop te vermijden.
