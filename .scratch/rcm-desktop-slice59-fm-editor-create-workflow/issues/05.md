## What to build

Read-only tab **Resultaten** in `FmEditorDialog`: FM-lifecycle-totalen uit laatste run (`expected_failures`, totale niet-beschikbaarheid CM+PM, kosten), PM-type-tellingen (IN/SVO/TST/REV), en PM-subtabel per taak (type, interval, taakgroep, **eerste uitvoeringsjaar** via LTAP-semantiek met `anchor_year=0`). Initiële leeftijd blijft op tab Basis (niet dubbel tonen als invoer). Lege staat vóór eerste run ("Opslaan om resultaten te berekenen"). Tab ververst na elke geslaagde **Opslaan** (hook uit opslaan-lifecycle slice). Adapter: `FmEditorResultsViewService` + frozen `FmEditorResultsView` DTO, Qt-vrij.

## Acceptance criteria

- [x] Tab **Resultaten** toont FM-totalen en PM-subtabel na run; lege staat vóór run
- [x] Eerste uitvoeringsjaar read-only per PM-rij (LTAP schedule)
- [x] Verversing na Opslaan; inspectorpaneel rechts blijft beschikbaar na sluiten editor
- [x] Unit tests `FmEditorResultsViewService`; smoke tab zichtbaar na save
