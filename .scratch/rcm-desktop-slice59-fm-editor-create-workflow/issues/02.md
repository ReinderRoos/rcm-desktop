## What to build

Breid `FmEditorDialog` uit met expliciete **opslaan-lifecycle** voor create én edit:

```text
OPEN → (Opslaan | Opslaan en sluiten) → COMMITTING → COMMITTED → OPEN (buffer reload)
OPEN → Annuleren → CLOSED (discard uncommitted delta only)
```

**Opslaan**: commit + incrementele run, editor blijft open, edit-buffer herladen uit sessie (geen divergentie PM-rijen/sessie). **Opslaan en sluiten**: Opslaan + close. **Annuleren**: waarschuwing bij dirty buffer sinds laatste Opslaan; eerdere Opslaan-acties blijven; clean buffer sluit zonder prompt. Opslaan geblokkeerd bij validatiefouten en tijdens lopende commit/run. Hook voor downstream tab-verversing (Resultaten-tab volgt in latere slice).

## Acceptance criteria

- [x] Knoppen **Opslaan**, **Opslaan en sluiten**, **Annuleren** met bovenstaande semantiek
- [x] Na Opslaan: buffer reload uit committed sessie; geen undo van eerdere commits
- [x] Dirty-check op Annuleren; save geblokkeerd tijdens run
- [x] Tests op commit-reload gedrag; pytest-qt smoke op knoppen in edit/create
