## What to build

Uitbreiding tab **Preventief** met taakgroep-UX: **Nieuwe taakgroep…** (inline mini-form, auto uniek group-id, koppel aan geselecteerde PM-rij), **Koppel aan bestaande maatregel…** (picker op unieke taakgroepen/PM-taken in project), en **preview** welke andere faalwijzen dezelfde groep delen. Adapter: `TaskGroupCatalogService` (lijst groepen + reverse index FM per groep), `PmMeasureLinkService` (stel `task_group_id` + gedeelde velden in). Bestaande PM CRUD, inline taakgroep-bewerking en gedeeld-gebruik-waarschuwing (slice 44/49) blijven werken. Geen wijziging motordeduplicatie.

## Acceptance criteria

- [x] **Nieuwe taakgroep…** maakt unieke groep aan en koppelt aan PM-rij
- [x] **Koppel aan bestaande maatregel…** toont picker met preview (omschrijving, interval, aantal FM's)
- [x] Gekoppelde PM erft interval/kosten/duur volgens bestaande motordocumentatie
- [x] Unit tests catalog + link service; smoke koppel-flow in editor
