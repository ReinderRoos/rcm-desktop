## What to build

End-to-end **create faalwijze** pad vanuit modus FM-detail: toolbar-knop **Nieuwe faalwijze** (alleen zichtbaar in FM-detail, geblokkeerd zonder leaf-PBS-selectie in sidebar) opent `FmEditorDialog` in create-modus met vaste `pbs_id`, auto-gegenereerd uniek `fm_id`, default `functie_id` (sibling op PBS, anders eerste projectfunctie), en minimumvalidatie (omschrijving, functie, `mttf_jaar > 0`).

Adapter-laag: `FmCreateService` (allocate id + default row), uitbreiding `FmEditScopeLoader` (`seed_create_bundle`), uitbreiding `FmEditCommitService` (`insert_fm_scope` parallel aan replace). Na geslaagde eerste save: incrementele run voor nieuwe `fm_id`, FM-tabel ververst met nieuwe rij (bij voorkeur geselecteerd). Bestaand dubbelklik-edit pad blijft ongewijzigd. Gebruik bestaand opslaan-en-sluiten-gedrag voor eerste save in v1 van deze slice.

## Acceptance criteria

- [x] Knop **Nieuwe faalwijze** alleen in FM-detail; disabled met duidelijke melding zonder leaf-PBS
- [x] Create-modus: `pbs_id` vast, `fm_id` auto uniek (`FM-###`), tabs Effecten/Correctief/Preventief mogen leeg bij eerste save
- [x] Validatiefouten (NL) blokkeren save; na save incrementele run en nieuwe FM zichtbaar in tabel
- [x] Unit tests voor `FmCreateService`, `seed_create_bundle`, `insert_fm_scope`; smoke test toolbar + dialog open
