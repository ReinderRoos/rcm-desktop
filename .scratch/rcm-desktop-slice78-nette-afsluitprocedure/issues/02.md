## What to build

Bedraad `ResultsWorkspaceWindow.closeEvent` op de Afsluit-planner (issue 01).

- Bepaal `grid_dirty` via `EditingHost.is_grid_dirty()` en `busy` via de bestaande
  runner-busy-detectie (`_update_run_buttons_enabled`-logica /
  `BackgroundRunner.isRunning`).
- **Grid-dirty:** hergebruik het `resolve_grid_dirty_before_editor`-patroon
  (opslaan → `invoke_grid_save()`; verwerpen → doorgaan; annuleren →
  `event.ignore()`). Mislukt opslaan → `event.ignore()`.
- **Busy:** toon bevestiging; afsluiten gekozen → `cancel()` op alle actieve runners
  + wacht netjes op beëindiging; annuleren → `event.ignore()`.
- Behoud de bestaande **model-detach** (anti-crash) vóór `event.accept()`.
- Geldt voor álle sluitpaden (OS-kruis, `Ctrl+Q`/Bestand→Afsluiten).

## Acceptance criteria

- [ ] Dirty grid + annuleren → `event.ignore()`, venster open.
- [ ] Dirty grid + opslaan (succes) → `invoke_grid_save()` aangeroepen, venster sluit.
- [ ] Opslaan mislukt → venster sluit niet.
- [ ] Busy runner + afsluiten → `cancel()` aangeroepen; venster sluit na beëindiging.
- [ ] Niets dirty/niets draaiend → sluit direct; model-detach blijft.
- [ ] pytest-qt met gemonkeypatchte `QMessageBox` dekt alle takken.
