# Issue 34 — Bundel-engine met all-or-nothing en reeks-shift

**Status:** done  
**Type:** AFK

## Parent

- `../PRD.md` (slice 11 — LTAP PM-bundeling)

## What to build

Implementeer een pure bundel-engine die geselecteerde PM-taak-id’s met een
integer `shift_years` kan verschuiven.

Gedragsregels:

- all-or-nothing validatie (één ongeldige taak => hele actie geblokkeerd);
- verschuiving herankert de hele toekomstige taakreeks;
- intervalpatroon loopt door vanaf de nieuwe ankerpositie.

De output van de engine moet een stabiel contract zijn dat de LTAP-view kan
consumeren.

## Acceptance criteria

- [x] Bundelactie werkt op selectie van PM-taak-id’s met integer jaarshift.
- [x] Ongeldige shift blokkeert de volledige actie met een duidelijke fout.
- [x] Reeks-shift herankert de toekomstige planning en behoudt intervalgedrag
      vanaf nieuw anker.
- [x] Engine is pure adapterlogica en los testbaar zonder Qt.
