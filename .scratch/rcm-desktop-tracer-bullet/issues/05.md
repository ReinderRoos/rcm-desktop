## What to build

`rcm_desktop.adapter.run_controller.RunController(QObject)`: orchestreert een
incremental analytical run zonder de UI-thread te blokkeren.

Signalen:
- `started()` — emit zodra worker begint.
- `progress(affected_count: int, total: int)` — vóór herrekening.
- `finished(result: IncrementalRunResult)` — succesvol klaar.
- `failed(exc: Exception)` — bij fout.

Methode: `start(project: RCMProject, project_path: str, full_recompute: bool = False)`.
Onder de motorkap: maakt een worker (`QRunnable` of dedicated `QThread`) die
`rcm_core.incremental_run.run_incremental_analysis` aanroept met een
`before_analytical`-callback die `progress` emit.

## Acceptance criteria

- [ ] TDD: tests in `tests/test_run_controller.py` schrijven eerst.
- [ ] `qtbot.waitSignal(controller.finished, timeout=...)` werkt voor een
      kleine fixture (gebruik bestaande pytest-fixtures of een mini-project).
- [ ] Bij geforceerde fout (mock op `rcm_core.incremental_run as ir`) wordt
      `failed`-signaal geëmit met de juiste exceptie.
- [ ] UI-thread niet geraakt: test bevestigt dat `started` op de UI-thread
      arriveert maar de berekening op een andere thread draait.
- [ ] Geen import van Qt-views in deze module.
