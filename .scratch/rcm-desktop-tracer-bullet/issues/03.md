## What to build

Eerste werkende PySide6 entry point: `python -m rcm_desktop.main` opent een
`QMainWindow` met menubar (`Bestand > Open fixture`, `Bestand > Sluiten`),
statusbar en een placeholder central widget. Geen modellen, geen data — alleen
windowing.

## Acceptance criteria

- [ ] `pip install -e .[dev]` slaagt; PySide6 staat in `pyproject.toml`.
- [ ] `python -m rcm_desktop.main` opent een venster en sluit netjes via
      `Bestand > Sluiten`.
- [ ] `Bestand > Open fixture` opent file-dialog (functionaliteit komt in 06,
      maar dialog werkt al).
- [ ] Smoke-test in `tests/` (optioneel met `pytest-qt`) bevestigt dat
      `main()` zonder excepties terug komt met `--exit-after-show` (vlag
      toegevoegd voor testbaarheid).
