**Status:** done

## What to build

Lever een uniforme confirm-flow voor destructieve acties wanneer dirty=true.

Voor validate, projectpadwissel en venster sluiten geldt exact dezelfde
beslissingstabel:

- `Opslaan` -> probeer save; ga alleen door bij succes;
- `Verwerpen` -> ga door en vervang/reset de edit-buffer;
- `Annuleren` -> breek de actie af.

Bij save-fout tijdens deze flow wordt de vervolgactie altijd afgebroken en
blijft de gebruiker in de huidige context met duidelijke foutmelding.

## Acceptance criteria

- [x] Validate met dirty=true toont unsaved-dialog met de drie afgesproken
      keuzes en correct vervolg per keuze.
- [x] Padwissel en sluiten gebruiken exact dezelfde policy en copy.
- [x] Bij save-fout vanuit de dialog wordt de oorspronkelijke destructieve actie
      niet uitgevoerd.
- [x] Dialog-flow is gecentraliseerd (geen divergerende logica per triggerpad).
- [x] Bestaande niet-dirty paden blijven ongewijzigd snel en zonder extra modal.
