## What to build

De **tracer bullet** van slice 87: PBS-scope + globale zoekbalk op het
entiteiten-grid, end-to-end op **Faalwijzen**.

End-to-end:

- Qt-vrije **Input-scope-policy**: per view-id `pbs_bound` vs `project_wide`;
  voor Faalwijzen directe `pbs_id` op de rij; subtree-check via
  `collect_pbs_subtree_ids`.
- Qt-vrije **zoektekst-builder**: haystack per rij (key_field altijd,
  zichtbare kolommen display + ruwe waarde).
- Generieke **Input-filter-proxy** (`scope_subtree` ∧ `search_text`, patroon
  `FaalwijzenFilterProxy`).
- **Entiteiten-grid-panel**: per-kolom filterrij vervangen door zoekbalk +
  rijtelling; scope via `set_scope()`.
- **Resultatenwerkruimte-venster**: bij `set_pbs_scope` en grid-`attach`
  huidige scope doorgeven aan het panel.

TDD: scope-policy → zoektekst → proxy → panel → dunne venster-wiring.

## Acceptance criteria

- [ ] Faalwijzen-view heeft geen per-kolom filterrij; wel één zoekbalk en
      rijtelling (gefilterd van totaal).
- [ ] Actieve PBS-scope toont alleen faalwijzen in de subtree; `scope_id=None`
      toont alles; onbekende scope levert lege tabel.
- [ ] Zoekbalk filtert deelstring, hoofdletterongevoelig, gecombineerd met
      scope (EN); zoek vindt key_field ook als kolom verborgen is.
- [ ] PBS-scope-wissel behoudt zoektekst; view-wissel wist zoektekst.
- [ ] Bewerken, dirty-markering en validatie werken ongewijzigd.
- [ ] Qt-vrije tests voor scope-policy en zoektekst; pytest-qt voor proxy en
      panel.
