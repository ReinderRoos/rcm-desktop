# Issue 02 — Gedeelde PBS/taakgroep-waarschuwingen uit edit-sessie

**Triage:** ready-for-agent  
**Type:** AFK

## Parent

PRD: `.scratch/rcm-desktop-slice45-fm-edit-hardening/PRD.md` (slice 45).

## What to build

In de **faalwijze-editor** (`FmEditorDialog`) tonen waarschuwingen als een PBS-item of taakgroep door **meerdere faalwijzen** wordt gedeeld. De tellers (`count_faalwijzen_for_pbs`, `count_faalwijzen_for_task_group`) gebruiken nu het **baseline-project** bij openen, niet de geïsoleerde **EditingSession** van de dialog.

Breid de Qt-vrije **FmEditBundleService** uit (of voeg dunne helpers toe) zodat tellen kan op basis van `edit_current`-buffers in de sessie (faalwijzen-rijen / PM-taken met `task_group_id`), zonder de hele dialog te herbouwen. De view roept deze helpers aan met de dialog-`EditingSession` in plaats van `self._project`.

Gedrag: waarschuwing blijft “meer dan één FM deelt dit PBS / deze taakgroep”; na in-sessie wijzigingen aan koppelingen moet de telling **sessie-actueel** zijn.

## Acceptance criteria

- [ ] Waarschuwing basis-tab (gedeeld PBS): telling gebruikt sessie-buffers, niet alleen baseline `RCMProject`.
- [ ] Waarschuwing preventief-tab (gedeelde taakgroep): idem voor geselecteerde `task_group_id`.
- [ ] Unit-test: fixture met twee FM’s opzelfde `pbs_id` → count ≥ 2 vanuit sessie; na verwijderen van één FM-rij uit sessie (of scope-wijziging) past count mee.
- [ ] Geen nieuwe Qt-imports in `FmEditBundleService`; view blijft delegatie naar adapter.
- [ ] Bestaande slice-44 adapter-tests blijven groen.
