## What to build

End-to-end **actiepad**: van suggestie naar overlay-shift met preview, zonder motor-run.

**Adapter (Qt-vrij, test-first):**

- Nieuwe **meekoppel apply bridge**:
  - Input: `RCMProject`, `PlanningOverlayState`, suggestie-rij, `anchor` default `"earlier"`.
  - Effectief due-jaar = `round(interval_jaar) + anchor_years.get(pm_id, 0)`.
  - Preview output: welke PM verschuift, `shift_years`, from/to jaren, `blocked_reason` (SVO/WET).
  - Apply delegeert aan bestaande `apply_overlay_shift`; overlay ongewijzigd bij blokkade.
- Default semantiek (prototype):

```
if anchor == "earlier":
    target_year = min(jaar_a, jaar_b)  # effectief
    shifted_pm = pm met later effectief due-jaar
else:
    target_year = max(jaar_a, jaar_b)
    shifted_pm = pm met eerder effectief due-jaar
shift_years = target_year - effective_due(shifted_pm)
```

**Werkruimte-UI:**

- Per suggestierij (of selectie): knoppen **Preview** en **Toepassen**.
- Preview: toont huidige → doeljaren, shift-samenvatting, blokkade; **muteert overlay niet**.
- Toepassen: overlay-shift + LCC-curve/jaartabel rerender via bestaande what-if-flow.
- Foutmelding bij apply-fout (zelfde toon als bundel-shift).
- Geen automatische motor-run; passieve taken blijven passief.
- Meerdere applies cumuleren op overlay (`change_count` stijgt).
- Reset naar baseline blijft werken.

**Tests:** unit tests preview/apply (default anker, SVO-blokkade, overlay met bestaande offset, succes verhoogt change_count).
