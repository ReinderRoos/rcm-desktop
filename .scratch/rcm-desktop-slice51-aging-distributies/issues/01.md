**Triage:** done  
**Type:** AFK

## Parent

PRD: `.scratch/rcm-desktop-slice51-aging-distributies/PRD.md` (slice 51).

## What to build

Lever een volledige verticale slice voor `aging_distribution = weibull_2p` van invoer tot zichtbaar resultaat.  
Een analist moet per faalwijze Weibull kunnen kiezen, `beta_jaar` kunnen invullen, en direct een correcte analytische aging-berekening krijgen (inclusief conditionering bij startleeftijd `a > 0`) zonder fallback naar bibliotheek tijdens runtime.

Deze slice omvat ook:

- harde validatie: bij Weibull is `beta_jaar > 0` verplicht;
- Monte Carlo-sampling voor Weibull en een parity-check tegen analytische uitkomst;
- conditionele UI in FM-editor en batch-grid voor Weibull-selectie en beta-invoer;
- behoud van architectuurgrens: views praten via adapter, distributiewiskunde blijft in kern.

## Acceptance criteria

- [x] Een faalwijze met `failure_type=aging` en `aging_distribution=weibull_2p` rekent analytisch correct met `eta = MTTF / Gamma(1 + 1/beta)` en conditionering `R(t|a)`.
- [x] Valideren blokkeert run wanneer `beta_jaar` ontbreekt, niet-numeriek is, of `<= 0` bij actieve Weibull.
- [x] FM-editor en batch-grid ondersteunen Weibull-keuze + `beta_jaar` bewerken; gedrag is zichtbaar zonder directe kernimports in views.
- [x] Er is een Monte Carlo parity-test voor Weibull (seeded) die analytisch gedrag regressievast maakt.
- [x] Bestaande random- en normal-paden blijven groen in de relevante regressietests.
