## What to build

Scheid de LCC **curve-cache key** van de **jaarselectie**. Introduceer pure adapter-functie(s) die uit `WorkspaceStateSnapshot` twee keys afleiden:

- `curve_key`: scope, type-filters, overlay `(active, change_count)` — **zonder** `lcc_calendar_year`
- `detail_key` (of detail-only invalidation): curve-identiteit + `calendar_year`

Vervang het monolithische LCC-gedeelte van `_render_cache_modus_key` zodat jaarklik de curve in `WorkspaceRenderIndex` **niet** invalideert. Jaardetail leest de gecachte curve + jaarselectie uit snapshot.

Prototype-beslissing:

```
curve_key   = f"lcc_curve|{scope}|{filters}|{overlay.active}|{overlay.change_count()}"
detail_tick = calendar_year  # geen curve rebuild
```
