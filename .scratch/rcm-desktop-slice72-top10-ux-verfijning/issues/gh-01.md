## What to build

Verwijder de Component/PBS-bronknop uit de Bijdragen-toolbar. Standaard bron wordt **faalwijze**. Analist zoomt op componentniveau via de PBS-boom.

Werk state, orchestrator, presentatie-cache-warmup en toolbar-sync bij. PBS-aggregatie blijft bij boomselectie.

## Acceptance criteria

- [ ] Geen zichtbare Component-bronknop in Bijdragen-modus.
- [ ] Nieuwe workspace-sessie start met faalwijze als bron.
- [ ] Top 10 toont faalwijze-ranking bij project-root.
- [ ] PBS-selectie in boom wijzigt nog steeds de bijdragen-scope.
- [ ] Tests voor default source en verwijderde toggle.
