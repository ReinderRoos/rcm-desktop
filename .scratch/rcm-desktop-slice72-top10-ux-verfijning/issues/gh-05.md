## What to build

Qt-vrije module `contribution_display_service` met gedeelde formattering voor bijdragen-waarden:

- `format_contribution_value` — waardekolom-semantiek (metric + NB uren/%).
- `format_contribution_bar_annotation` — compacte string voor staafdiagram.

Geen Qt-imports. Tabelmodel delegeert zolang het bestaat.

- [ ] Eén implementatie; geen gedupliceerde format-logica in chart-widget.
