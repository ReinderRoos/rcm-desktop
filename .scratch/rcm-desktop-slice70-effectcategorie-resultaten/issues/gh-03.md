## What to build

Qt-vrije deep module als SSOT voor effectaggregatie:

```
aggregate(project, fm_results, *, scope_id, metric, presentation, categorie_filter?)
  → tuple[EffectImpactRow, ...]
```

`EffectImpactRow`: klasse_id, label, categorie, rf_display, waarde_cm, waarde_pm, waarde_totaal, eenheid, share_pct.

Categorie-formules (spike §2):

- **beschikbaarheid** → NB per effect (uren) uit CM downtime × RF + PM-uren
- **veiligheid** → veiligheidsincidenten (CM incidenten-equivalent)
- **overig** → incidenten + waarschuwing

SSOT helper: `collect_fm_ids_for_functie(project, functie_id, kind)` — vervangt duplicatie in chart/rapport services.

Alle toekomstige consumenten (Top 10, inspector, KPI, rapport, export, pariteit) delegeren hiernaartoe.
