## What to build

Lever de **pure adapterlaag** die de bewerk-keten voor faalwijzen mogelijk
maakt, **zonder Qt**. Deze service is de single waarheid voor de bewerkbare
slice 7-kolomset boven `rcm_core.editing.*`, en levert het run-snapshot dat
slice 7 lazy materialiseert.

End-to-end gedrag van deze slice (zonder UI):

- **Init/reset uit `RCMProject`**: bouwt een interne edit-session met de
  laatst-gevalideerde basis, met identieke **store_key/key_field/field_types**
  als `ENTITY_SCHEMAS["faalwijzes"]`.
- **Read** levert rijen-DTOs voor de slice 7-kolommen:
  - **Read-only context:** `fm_id`, `pbs_id`.
  - **Bewerkbaar:** `faalwijze_omschrijving`, `functie_id` (FK),
    `mttf_jaar`, `sigma_jaar`, `cost_cm_eur`, `p_ongewenste_gebeurtenis`.
  - Per rij/per veld bekende **errors** (lijst met code + message), zodat de
    Qt-laag deze rechtstreeks kan tonen.
- **Write** via `apply_change(fm_id, field, raw_value)`:
  - Voert **typecoercion** uit volgens schema; bij numerieke velden wordt
    NL-decimaalkomma (`1,5`) **adapter-zijdig** vertaald naar `.` voor
    coercion **als** de bestaande `coerce_value` dat zelf niet doet.
  - Voert **per-rij validatie** uit minimaal voor de geraakte rij
    (eventueel over alle rijen toegestaan zolang gedrag deterministisch is).
  - Update interne edit-buffer; updateert ook eventuele FK-/domeinerrors.
- **Status-API**:
  - `has_errors() -> bool`, `error_count() -> int`.
  - `changed`-callback (callable die de UI later inhaakt op Run-knop-gating
    en op visuele rerender).
- **Materialize voor Run**:
  - `materialize_for_run() -> RCMProject`: voert `validate_all_entities` +
    `build_project_from_state` uit en levert een **vers** `RCMProject`-
    snapshot.
  - Raised een **typed error** (eigen exception of geretourneerd
    Result-object) als er nog edit-errors zijn; **geen run-snapshot**
    in dat geval.
- **Reset**: gooit de huidige edit-buffer weg en herstart op een gegeven
  `RCMProject` (bv. nieuw gevalideerd project of expliciete cancel-flow uit
  een toekomstige slice).

Geen Qt-imports. Architectuurregel: views mogen `editing.*` niet direct
importeren; alle bindings via deze service.

### Beslissingsschema (samengevat uit PRD)

```
Bewerkbare kolommen   : faalwijze_omschrijving, functie_id,
                        mttf_jaar, sigma_jaar, cost_cm_eur,
                        p_ongewenste_gebeurtenis
Read-only kolommen    : fm_id, pbs_id
NL-decimaalkomma      : adapter-zijdig vertalen indien nodig
Validatie-laag        : editing.validation (typecoercion + domeinregels)
Materialisatie-pad    : validate_all_entities + build_project_from_state
Materialisatie-policy : weigert bij has_errors == true
Reset                 : harde reset bij path-/validate-reset (caller-driven)
```

## Acceptance criteria

- [ ] Pure module zonder Qt-imports; nieuwe service in adapterlaag, niet in
      `rcm_core.*`.
- [ ] `init(project)` / `reset(project)` werkt op een fixture-`RCMProject` en
      levert correct gevulde rijen-DTOs voor de slice 7-kolomset.
- [ ] `rows()` retourneert **read-only** velden voor `fm_id` en `pbs_id` en
      **bewerkbaar** gemarkeerd voor de andere zes velden.
- [ ] `apply_change` voor `mttf_jaar` met geldige numerieke waarde update de
      rij; geen errors.
- [ ] `apply_change` voor `mttf_jaar = 0` produceert
      `FM_MTTF_NONPOSITIVE`-error op exact de geraakte cel; `has_errors()`
      true; `error_count()` ≥ 1.
- [ ] `apply_change` voor `functie_id` met onbekende waarde produceert een
      FK-error; `has_errors()` true.
- [ ] `apply_change` voor `cost_cm_eur` met NL-input `"1,5"` levert intern
      `1.5` op (of vastgelegde gecontroleerde policy-fout indien expliciet
      ander gedrag wordt gekozen).
- [ ] `apply_change` voor `faalwijze_omschrijving` accepteert vrije tekst en
      veroorzaakt geen errors.
- [ ] `materialize_for_run()` retourneert een **nieuw** `RCMProject` waarvan
      de FM-objecten de gewijzigde waarden dragen (niet hetzelfde
      objectreferentie als input).
- [ ] `materialize_for_run()` weigert (typed error / Result-mismatch) zolang
      `has_errors()` true is; geen mutaties op input-`RCMProject`.
- [ ] `reset(project)` herstelt rijen-DTOs naar originele staat (no edits).
- [ ] `changed`-callback (of equivalent) wordt aangeroepen bij elke
      succesvolle `apply_change`.
- [ ] Bestaande `rcm_core.*`-tests blijven groen; nieuwe unit-tests dekken
      de happy-path en de error-paths hierboven.
- [ ] `python -m pytest` is volledig groen.
