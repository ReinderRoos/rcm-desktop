**Status:** done

## Parent

## What to build

Lever een eerste complete verticale slice voor jaargestuurde LTAP-detailweergave
die ook zonder chartmodule bruikbaar blijft.

Deze slice introduceert:

- selectie van een lifecycle-jaar;
- detailtabel met what-if werkzaamheden van het gekozen jaar;
- duidelijke empty-state bij jaren zonder werkzaamheden;
- expliciete actie "Toon alle jaren" om filter op te heffen.

De interactie moet fallback-first werken: ook zonder grafiekcomponent blijft
de jaarselectieflow volledig bruikbaar.

## Acceptance criteria

- [x] Gebruiker kan een lifecycle-jaar selecteren en ziet dan de what-if werkzaamheden + kosten van precies dat jaar.
- [x] Bij een geselecteerd jaar zonder werkzaamheden toont de UI een expliciete empty-state (geen stille lege tabel).
- [x] "Toon alle jaren" heft de jaarfilter op en herstelt totaaloverzicht.
- [x] Dezelfde jaarselectieflow werkt functioneel zonder QtCharts (lijstselectie + detailtabel).
