## What to build

**Tracer bullet** voor operationele consolidatie (werkstroom A): elke push en pull
request draait automatisch de testsuite op GitHub Actions, zodat regressies niet
afhangen van lokale pytest-discipline.

End-to-end:

- Workflow onder `.github/workflows/` voor remote `ReinderRoos/rcm-desktop`.
- Draait de bestaande pytest-configuratie (perf-tests uitgesloten via
  `-m 'not perf'`, conform `pyproject.toml`).
- Qt-tests headless (`QT_QPA_PLATFORM=offscreen` of equivalent).
- Python 3.11+, dependencies installeren uit `pyproject.toml`.
- Optioneel: aparte scheduled job voor `-m perf` (niet-blokkerend voor PR's).

De workflow is af wanneer een schone runner de volledige niet-perf suite groen
draait.

## Acceptance criteria

- [ ] Push en pull request triggeren de CI-workflow.
- [ ] De workflow draait de testsuite zonder perf-marker en faalt bij rode tests.
- [ ] Qt-tests draaien headless zonder display-afhankelijkheid.
- [ ] CI gebruikt Python 3.11+ en installeert projectdependencies correct.
- [ ] (Optioneel) Perf-tests draaien op schedule, los van PR-blokkering.
