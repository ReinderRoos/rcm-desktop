## What to build

Vervang **Analyse** door **Run → A** en **Run → B**. Gedeeld pre-run config-paneel (scenario Project/CM/PM + bestaande overlay/meekoppel) wordt bij run bevroren in het slot-snapshot. `CompareRunService` orchestreert de slot-run; `CompareRunRunner` draait op de achtergrond. `last_run` volgt de meest recente succesvolle slot-run. Bij run-fout blijven andere slot en vorige run van hetzelfde slot intact.

## Acceptance criteria

- [ ] Toolbar toont Run → A en Run → B i.p.v. enkele Analyse-knop
- [ ] Pre-run scenario-selector (Project/CM/PM) gedeeld met overlay/meekoppel-config
- [ ] Run bevriest `scenario_key` en `overlay_at_run` in snapshot met leesbaar label
- [ ] `CompareRunService` zonder Qt; `CompareRunRunner` in background thread
- [ ] `last_run` bijgewerkt naar meest recente succesvolle slot-run
- [ ] Mislukte Run → B laat slot A en vorige B intact; foutdialoog
- [ ] Unit-tests voor `CompareRunService` en `CompareWorkspaceController` post-run plan
- [ ] Nederlandse labels via message constants
