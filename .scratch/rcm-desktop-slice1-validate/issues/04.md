# Issue 04 — Resultaatweergave end-to-end (status + summary + uitklapdetails)

**Status:** ready-for-human  
**Type:** AFK  
**User stories covered:** US4

## Parent

Bron: `../PRD.md`.

## What to build

Lever een complete resultaatpresentatie na validate die direct bruikbaar is voor
de analist: duidelijke eindstatus, korte samenvatting en uitklapbare details.
De weergave moet per run worden ververst zodat oude output geen verwarring
geeft.

## Acceptance criteria

- [x] UI toont na validate een expliciete eindstatus (`Geldig`/`Ongeldig`/`Fout`).
- [x] UI toont een korte samenvatting en een details-paneel dat standaard
      ingeklapt is en handmatig uitgeklapt kan worden.
- [x] Een nieuwe validate-run vervangt de volledige vorige output (geen gemengde
      resultaten).
