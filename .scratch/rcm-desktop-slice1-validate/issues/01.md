# Issue 01 — Adapter-contract + validate mapping (incl. tests)

**Status:** ready-for-human  
**Type:** AFK  
**User stories covered:** US5 (en fundament voor US3/US4)

## Parent

Bron: `../PRD.md`.

## What to build

Lever een end-to-end validate-contract waarmee UI-consumenten consistent
kunnen renderen: status, samenvatting, details en foutinformatie. De slice
omvat ook de testbare vertaling van kernuitkomsten naar dit contract, inclusief
happy path en error path.

## Acceptance criteria

- [x] Validate-uitkomst wordt gemapt naar een stabiel adaptercontract met
      `status`, `summary`, `details` en optionele `error`.
- [x] Happy-path test bewijst dat een geldig projectbestand resulteert in een
      bruikbaar `valid` resultaat voor UI.
- [x] Error-path tests bewijzen dat ontbrekend en ongeldig inputbestand leiden
      tot consistente user-facing foutinformatie.

## Blocked by

None - kan direct starten.
