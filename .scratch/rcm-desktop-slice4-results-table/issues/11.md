## What to build

Lever de pure adapterlaag voor de faalwijzen-resultatentabel op, zonder Qt-UI.
Deze slice verrijkt het run-contract met rijniveau-data en centraliseert
Nederlandse getalopmaak zodat de volgende slice de tabel direct kan renderen.

End-to-end gedrag van deze slice (zonder view-aanpassingen):

- Nieuwe pure module `rcm_desktop.formatting` met:
  - `format_int(n: int) -> str`
  - `format_float(x: float, decimals: int = 2) -> str`
  - `format_eur(x: float, decimals: int = 2) -> str`
  Deterministisch, zonder `locale.setlocale`.
- Nieuwe pure module `rcm_desktop.adapter.result_view_service` met:
  - `FMResultRow` dataclass (7 velden)
  - `build_rows(project, fm_results) -> list[FMResultRow]`
- `RunResult` wordt additief uitgebreid met `rows: list[FMResultRow]` (default `[]`).
- `run_service.run(...)` vult op happy path zowel `metrics` als `rows` in één
  aanroep; bij foutpaden (`RUN_PRECONDITION_NOT_MET`, `RUN_INTERNAL_ERROR`)
  blijft `rows == []`.
- `build_rows(...)` joint defensief op `project.faalwijzes` en
  `project.pbs_items`; onbekende `pbs_id` geeft `bouwdeel_naam == ""` i.p.v.
  exception.

## Acceptance criteria

- [x] `rcm_desktop.formatting` bestaat met `format_int`, `format_float`,
      `format_eur` en gebruikt geen locale-global state.
- [x] `format_int(12345)` geeft `"12.345"`, `format_float(1234.5)` geeft
      `"1.234,50"`, `format_eur(1200.0)` geeft `"€ 1.200,00"`.
- [x] `rcm_desktop.adapter.result_view_service` bestaat met `FMResultRow`
      en `build_rows(project, fm_results)`; geen Qt-imports.
- [x] `FMResultRow` bevat exact:
      `fm_id`, `faalwijze_omschrijving`, `pbs_id`, `bouwdeel_naam`,
      `expected_failures`, `expected_total_downtime_hr`, `total_cost_eur`.
- [x] `build_rows(...)` mapt de 7 velden correct vanuit `FMResult` plus
      project-joins op faalwijze/PBS.
- [x] Bij onbekende `pbs_id` in een `FMResult` levert `build_rows(...)`
      `bouwdeel_naam == ""` en geen exception.
- [x] Lege input (`fm_results == []`) geeft `[]`.
- [x] `RunResult` heeft nieuw veld `rows` met default `[]`; bestaande
      contractvelden blijven semantisch gelijk.
- [x] Happy path in `run_service.run(...)` levert gevulde `rows` met correcte
      lengte en inhoud.
- [x] Foutpaden in `run_service.run(...)` leveren `rows == []`.
- [x] Bestaande mode-doorgifte (`full_recompute`, `parallel`) blijft correct.
- [x] `python -m pytest` is volledig groen.
