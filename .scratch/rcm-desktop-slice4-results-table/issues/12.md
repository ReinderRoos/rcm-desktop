## What to build

Maak de faalwijzen-resultaten zichtbaar in de Qt-UI na een geslaagde
`run --full`. Deze slice bouwt het tabelmodel, de sorting-koppeling en de
window-bedrading inclusief reset-discipline en formatting-migratie van het
bestaande run-paneel.

End-to-end gedrag van deze slice:

- Nieuwe `FMResultsTableModel(QAbstractTableModel)` in `rcm_desktop.adapter`
  met 7 vaste kolommen conform `FMResultRow`.
- `DisplayRole` toont NL-geformatteerde waarden (incl. `€ ` voor kosten),
  `UserRole + 1` levert raw numerics voor sorteerkolommen.
- `headerData(...)` gebruikt gecentraliseerde NL-kolomkoppen uit
  `rcm_desktop.messages`.
- `validate_window` krijgt onder het run-paneel een nieuw `QGroupBox`
  "Faalwijzen-resultaten" met `QTableView` + `QSortFilterProxyModel` en
  `setSortRole(Qt.UserRole + 1)`.
- Paneel zichtbaar uitsluitend bij `last_run.status == "done"` én
  `len(last_run.rows) > 0`; anders verborgen.
- Default-sort voor elk nieuw `done`-result: kosten aflopend.
- Reset-discipline: paneel hidden + model leeg bij pad-wijziging, nieuwe
  validate, nieuwe run, run-error en `run_changed(None)`.
- Bestaande run-KPI-weergave migreert naar `rcm_desktop.formatting` voor
  consistente NL-notatie.

## Acceptance criteria

- [x] `FMResultsTableModel` bestaat met correcte `rowCount`, `columnCount`,
      `headerData`, `data(DisplayRole)` en `data(UserRole + 1)`.
- [x] Sorteerkolommen (`expected_failures`, `expected_total_downtime_hr`,
      `total_cost_eur`) leveren raw numerics op `UserRole + 1`.
- [x] Stringkolommen leveren op `UserRole + 1` gewoon de stringwaarde.
- [x] `messages.py` bevat nieuwe NL-strings voor tabelgroep en kolomheaders
      met vocabulaire **"faalmomenten"** en **"niet-beschikbaarheid"**.
- [x] `validate_window` toont nieuw paneel "Faalwijzen-resultaten" onder
      "Analyseresultaat", met `QTableView` via `QSortFilterProxyModel`.
- [x] Bij `done` + non-empty rows is paneel zichtbaar en staat default-sort op
      kosten aflopend.
- [x] Bij `done` + lege rows is paneel verborgen (geen placeholderrij).
- [x] Bij run-error, pad-wijziging, start nieuwe validate/run en `None` wordt
      paneel verborgen en model gewist.
- [x] Run-paneel KPI’s gebruiken NL-formatting (`format_int/float/eur`) i.p.v.
      ruwe `str(...)`.
- [x] Architectuurregel blijft intact: geen directe `rcm_core`-imports in views
      (behalve typing waar strikt nodig).
- [x] Qt-tests gebruiken `pytest.importorskip("PySide6")`.
- [x] `python -m pytest` is volledig groen.
