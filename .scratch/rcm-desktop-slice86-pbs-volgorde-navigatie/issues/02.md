## What to build

De analist kan een PBS-item binnen zijn niveau omhoog/omlaag verplaatsen —
zonder her-run.

End-to-end:

- PBS-boommodel (adapter): broers/zussen gesorteerd op `volgorde` (met de
  bestaande volgorde als fallback).
- Reorder-operatie: volgorde-**swap met de buur**, via de normale
  editing/dirty-flow (dirty, save; geen apart persistentiepad). Verplaatsen
  wijzigt **nooit** de parent — geen re-parenting, geen niveau-wissel.
- Sneltoets `Ctrl+Alt+↑`/`Ctrl+Alt+↓` verplaatst het geselecteerde item één
  positie binnen zijn niveau; registratie via de menubalk-spec
  (uniciteitsvalidatie).
- Reorder triggert géén her-run: resultaten blijven geldig; alle weergaves
  die PBS-volgorde gebruiken volgen de boom.

## Acceptance criteria

- [ ] Boommodel sorteert broers/zussen op `volgorde`.
- [ ] Swap verwisselt precies twee buren en markeert het project dirty.
- [ ] Eerste item omhoog / laatste omlaag is een no-op (geen crash).
- [ ] `Ctrl+Alt+↑/↓` verplaatst het item zichtbaar in de boom (pytest-qt).
- [ ] Geen run wordt gestart na reorder (seam: patch op
      `rcm_core.incremental_run as ir`).
- [ ] Menubalk-spec golden bijgewerkt; sneltoetsen uniek.
