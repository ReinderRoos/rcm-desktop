# Issue 03 — Navigatie-sneltoetsen `Alt+↑/↓/←/→` in de PBS-boom

**Triage:** ready-for-agent  
**Type:** AFK

## Parent

PRD: `.scratch/rcm-desktop-slice86-pbs-volgorde-navigatie/PRD.md` (slice 86).

## What to build

Muisloze navigatie door de PBS-boom.

End-to-end:

- `Alt+↑` / `Alt+↓`: selectie naar vorige/volgende item op hetzelfde niveau
  (langs broers/zussen, in `volgorde`-volgorde).
- `Alt+←` / `Alt+→`: naar parent / eerste kind (de diepte uit/in).
- Registratie via de menubalk-spec zodat de uniciteitsvalidatie ze dekt
  (conflictcontrole met sneltoetsen van slice 76/79).
- `Alt+pijlen` kan botsen met Qt-default focusnavigatie: alleen actief bij
  boomfocus; documenteer dit in de spec.
- Randgedrag: eerste/laatste broer, root (geen parent), blad (geen kind) →
  no-op.

## Acceptance criteria

- [ ] Vier sneltoetsen navigeren correct (pytest-qt, incl. randgevallen).
- [ ] Sneltoetsen alleen actief bij boomfocus; geen interferentie met
      tabellen/invoervelden.
- [ ] Menubalk-spec golden bijgewerkt; validator dekt de nieuwe sneltoetsen.
